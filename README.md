## 2026-01-28

Q: 总结下 好运笔记.md中股票交易重要的10点

A: 根据《stock/好运/好运笔记.md》整理出的10条要点：
1. 关注成交量与成交金额排行榜，优先选择活跃度高、流动性好的品种。
2. 前期涨幅过大的不追高，等回调后再评估建仓，避免站岗。
3. 对没有长期跟踪的标的谨慎，避免临时起意的随手买入。
4. 调整行情中涨幅超过3%不买，追高风险大。
5. 低位可先小仓试错，确认方向与市场配合再加仓。
6. 在指数单边上涨阶段积极做多；震荡降低仓位；下跌趋势倾向空仓或严格止损。
7. 跟随主线板块（如文中多次提到的大科技）而不是分散追热点。
8. 低吸高抛，尤其在恐慌急跌时更重视纪律与节奏。
9. 大幅上涨的票下跌也会很凶，缺乏低位利润保障时不要追高。
10. 赚钱要及时落袋、控制贪念，执行力比懂道理更关键。
